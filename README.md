# cramrade-media

Finished marketing videos for Cramrade's TikTok, Instagram Reels and YouTube Shorts, plus the code that renders them.

- `videos/<year>-W<week>/` holds the week's MP4s. Buffer downloads them from their raw GitHub links when it publishes.
- `engine/` renders pixel-style videos from small JSON scripts (see `engine/README.md`).
- `RUNBOOK.md` is the step-by-step a scheduled Claude session follows every Sunday.

Everything here is public. Never commit keys, passwords or user data.
